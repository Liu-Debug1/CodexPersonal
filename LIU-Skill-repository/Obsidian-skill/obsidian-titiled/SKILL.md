# Obsidian 标题整理

将 Obsidian Markdown 笔记的标题整理为层级分明的中文数字编号体系。

## 标题层级规则

| Markdown 层级 | 编号格式 | 示例 |
|-------------|---------|------|
| `#` (H1) | 文档标题，不加编号 | `# Claude Code 使用指南` |
| `##` (H2) | 中文数字：一、二、三... | `## 一、应用方式` |
| `###` (H3) | `章节.序号` | `### 7.1 上下文压缩` |
| `####` (H4) | `章节.序号.子序号` | `#### 7.4.1 初始化仓库` |
| `#####` (H5) | `章节.序号.子序号.孙序号` | `##### 7.4.1.1 详细步骤` |

- H1 作为文档主标题，不参与编号体系
- H2 以下每一层用父级编号作为前缀，跟随数字编号

## 整理流程

### 1. 分析现有结构

先通读全文，识别所有标题及其层级关系，确定哪些 H2/H3/H4 归属于哪个父标题。

### 2. 编号规则

- H2（一级标题）从 **一** 开始，连续递增，中间不允许跳号
- H3（二级标题）在每个 H2 章节内从 **.1** 开始重新编号
- H4（三级标题）在每个 H3 小节内从 **.1** 开始重新编号
- H5（四级标题）以此类推

### 3. 检查与修复

- **跳号修复**：如发现一→二→四（缺三），将四改为三，后续依次前提
- **子编号一致性**：子标题前缀必须与所属 H2 编号一致。如 H2 为"三"，其下 H3 应从 3.1 开始
- **混合格式统一**：如部分 H3 用 `1.` 部分用 `### 1.1`，统一为 `### 章节.序号` 格式

### 4. 仅修改标题行

只改 `#` 开头的标题行，不改动正文内容、表格、代码块、callout 等。

## 示例

**整理前：**
```markdown
# 我的笔记

## 一、概述
### 背景介绍
### 1.1 目标
## 三、详细说明
### 方法一
### 方法二
```

**整理后：**
```markdown
# 我的笔记

## 一、概述
### 1.1 背景介绍
### 1.2 目标
## 二、详细说明
### 2.1 方法一
### 2.2 方法二
```

## 注意事项

- 保留标题中已有的文字描述，只修改编号部分
- 如果标题已有 `X.Y` 格式编号但与章节不匹配，以章节编号为准进行修正
- 处理完后输出修改后的标题大纲（仅标题行），方便用户确认结构
