# Obsidian 内容列表化

将笔记中密集的段落式描述转换为层级列表，让笔记更紧凑、更易扫读。不改代码块、表格、callout——只动 prose 段落。

## 核心原则

### 必须保留（不改动）
- 代码块、表格、Callout（`> [!note]` 等）、ASCII 框图、Wikilink、图片引用
- 标题层级（`###` / `####`）——不为了列表而新增或拆分标题
- 单句类比、一句话总结、过渡句

### 只转换这些
- 密集 prose 里罗列了多个要点 → 拆成列表
- "首先...其次...最后..." → 有序列表
- "包括...、...、以及..." 枚举句式 → 无序列表
- 对比/区别描述 → 能建表就建表，不能就用嵌套列表
- 因果式长句 → 拆为层级缩进列表（但不滥用 → 符号，用自然短语表达）

## 转换规则

### 规则 1：并列要点 → 无序列表

```
内存泄漏的常见原因有：忘记 delete、异常导致的提前返回、循环中不断 new 却不释放。
```
↓
```
内存泄漏常见原因：
- 忘记 `delete`
- 异常导致提前返回
- 循环中不断 `new` 不释放
```

### 规则 2：有序步骤 → 有序列表

```
首先要检查分配是否成功，然后用指针操作数据，最后调用 delete 释放并置 nullptr。
```
↓
```
1. `new` 分配内存
2. 检查是否分配成功（是否 `nullptr`）
3. 通过指针操作数据
4. `delete` 释放
5. 指针置 `nullptr`
```

### 规则 3：因果/层级关系 → 层级缩进列表

长句拆成短要点，用缩进表达层级，不要强行用 → 堆叠：

```
类型兼容性导致基类指针可持有子类对象，迟早要释放它，所以析构函数必须是虚的，否则子类资源泄漏。
```
↓
```
- 类型兼容性 → 基类指针可持有子类对象
- 这导致一个后果：迟早要通过基类指针释放对象
- 因此基类析构必须是 virtual
- 非虚析构 → 子类析构不会被调用 → 子类资源泄漏
```

### 规则 4：对比信息 → 表格优先

两个维度、三点以内且描述短 → 用列表对比；多维度、长描述 → 用表格。

**列表对比示例**：
```
- **C 风格转换**：一个语法做三件事，编译器不检查，grep 搜不到
- **C++ 命名转换**：四种各司其职，编译器校验，意图写在脸上
```

### 规则 5：注意点/坑点 → 精简短列表

```
在使用指针时，不能使用未初始化的指针，释放后要置空，不能多次释放同一块内存，不要返回局部变量地址。
```
↓
```
- 不能用未初始化的指针
- 释放后立即置空
- 不能多次释放同一块内存
- 函数中不要返回局部变量地址
```

### 规则 6：特定场景提醒 → Callout + 列表

```markdown
> [!warning] 嵌入式注意
> - MCU 栈通常只有几 KB，大数组放栈上可能溢出
> - 溢出后变量被莫名其妙改，程序跑飞
```

## 工作流程

1. **通读当前章节**，定位 prose 密集段落（通常 3 行以上的纯文字段）
2. **判断转换类型**：并列枚举？有序步骤？因果链？对比？
3. **逐段转换**，每改完一段自检：内容是否完整？是否比原文更紧凑易读？
4. **不要过度列表化**——单句类比、一句话总结、过渡句保留原样
5. **保持标题层级不变**——除非原文编号跳号才顺手修正

## 与其他 Obsidian Skill 的协作

- **先跑 `obsidian-contentList`，再跑 `obsidian-titiled`**：列表化可能导致标题编号偏移（如果合并了子标题），交给 titiled 统一修
- **不要碰代码块**：`Obsidian-PhotoToCode` 生成的代码块也属于不改动范围
- **主动提醒**：如果发现大量 prose 改造后标题层级需要重排，主动建议用户跑 `obsidian-titiled`

## 完整示例

**优化前**：
```markdown
### 1.2 变量声明

C++ 允许在 for 循环内部声明循环变量，而 C 语言要求必须在函数开头声明所有变量。另外 C++ 新增了两种初始化方式，其中用小括号 () 可以初始化基本类型和 string 类型，用花括号 {} 可以初始化一切类型。需要注意对于数组和字符串，只能用花括号初始化不能用小括号，而且花括号初始化时未占满的位置会自动被初始化为零。
```

**优化后**：
```markdown
### 1.2 变量声明

**与 C 的区别**：
- C++ 允许在 `for` 循环内声明循环变量（C 必须在函数开头）

**新增初始化方式**：
- `()` 初始化：基本类型、`string` 类型
- `{}` 初始化：一切类型
  - 数组、字符串只能用 `{}`
  - 未占满的位置自动补零
```
