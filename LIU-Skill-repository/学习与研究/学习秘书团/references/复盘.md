# 复盘官——组卷调度

## 每日组卷

```
0. 从 # currentDate 读取今天日期
1. 读问题状态库，筛选"下次复习 <= 今天"的错题 → 统计 M
2. 错题无上限：全部必做
3. M 传给问题官 → 计算新题量 + 题型分配 + 按顺序出题
4. 逐题考错题（问题官同步后台出新题）
5. 每题进度标签：错题X/M - 题型 - 题源
6. 错题考完 → 新题就绪 → 按顺序逐题考
7. 每题进度标签：新题X/N - 题型 - 题源
8. 全部考完 → 批改 → 更新状态库
```

## 出题顺序（强制执行）

```
选择题 → 判断题 → 填空题 → 代码补全题 → 简答题 → 评价题
```

错题考完后，新题严格按此顺序呈现。

## 新题数量公式

```
新题量 = 8 - floor(M / 5)，最少 3 道
```

## 题型分配

- 难题三选二：{代码补全, 简答, 评价} 每天抽 2 种，各 1 题
- 剩余配额：平均分配选择、判断、填空

详见 `references/出题.md`。

## 1-3-7 状态流转（仅错题参与）

**核心：只有首次答错的题才进入 1-3-7 循环。新题首次答对 → 普通题删除，#重点保留于题库但不写入状态库。**

```
首次答错 → 写入状态库，状态="待复习" → 隔天考
              ↓ 正确
         状态="第3天" → 3天后考
              ↓ 正确
         状态="第7天" → 7天后考
              ↓ 正确 → 从状态库删除（#重点回到题库保留）

任意一次错误 → 回退到"待复习"，隔天再考
```

## 问题状态库维护

| ID | 问题摘要 | 来源 | 创建日 | 状态 | 正确次数 | 下次复习 | 备注 |
|----|---------|------|--------|------|---------|---------|------|

- 新题首次答对 → 不写入状态库（普通题删，#重点留题库）
- 错题第7天答对 → 从状态库删除
- 答错 → 更新状态 + 下次复习日
