# 排版规则

## 分点文字

- 使用 DOCX 中前 N 条非空段落，对应 N 个页码范围。
- 保持段落文字逐字不变，只添加 `1.`、`2.`、`3.` 等前缀。
- 不创建独立说明页。
- 在每个范围的首个 PDF 页面顶部增加标题区，原学习内容紧随其后。
- 仅缩放和下移范围首个页面；其余源 PDF 页面必须保持内容流与页面框不变。
- 页面尺寸沿用源 PDF，不强制转换 A4 或 A3。

## 代码截图

- 按 DOCX 中出现顺序提取图片。
- 每页最多放三张，使用 A3/源页面横向尺寸紧密排列。
- 只在第一张截图拼版页顶部写一次“复用函数模板”。
- 不显示 `1/3`、`2/3` 等编号，不为每张截图另起一页，不重复说明文字。
- 图片保持宽高比，不裁切，不拉伸。

## 输出与验证

- 默认文件名使用 `<学习内容文件名>_按学习汇报对应整理_最终.pdf`。
- 禁止覆盖 DOCX 和源 PDF。
- 为各分点和代码截图拼版添加书签。
- 对未修改的源 PDF 页面进行内容流哈希校验。
- 以 120 DPI 渲染全部页面；检查渲染页数、空白页和页面尺寸。
- 生成四页一张的联系表供视觉检查，但不向用户交付联系表。
