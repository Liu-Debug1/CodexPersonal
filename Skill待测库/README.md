# Skill 待测库

这里保存尚未进入个人库的候选 Skill、Plugin、MCP 和 CLI 资产。待测资产不得直接部署到任何项目。

## 目录

```text
Skill待测库/
├── skills/
├── plugins/
├── mcp/
├── cli/
└── 测试记录.md
```

## 晋级条件

1. 记录来源地址、版本或提交、许可证、依赖和所需权限。
2. 审查文件、脚本、网络访问、写入行为和凭据要求。
3. 在隔离或明确的测试场景完成实际试用。
4. 在 `测试记录.md` 记录结论后，才可复制到 `LIU-Skill-repository/` 或项目包。
