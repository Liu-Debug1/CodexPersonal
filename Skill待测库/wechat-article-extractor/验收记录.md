## 2. 权限、依赖与风险

### 权限和行为

- 声明会向 `mp.weixin.qq.com` 和可选的 `weixin.sogou.com` 发起网络请求，读取公众号文章内容。
- 声明会解析文章 HTML 并返回标题、作者、发布时间、封面和正文等数据。
- 根目录的 `convert.js` 会读取和写入本地文件；其输入、输出路径硬编码为作者 macOS 的绝对路径。
- 未发现凭据、环境变量读取、子进程执行或系统命令调用。

### 依赖

直接依赖为 `cheerio@^1.2.0`、`dayjs@^1.11.19`、`lodash.unescape@^4.0.1`、`qs@^6.15.0` 和 `request-promise@^4.2.6`。

### 风险

- `request-promise` 引入已废弃的 `request` 依赖链。
- `npm audit --package-lock-only --omit=dev` 报告 10 项生产依赖漏洞：2 项 critical、2 项 high、6 项 moderate。
- 文档和 README 都要求 `./scripts/extract.js`，但当前检出内容中没有 `scripts/`、`extract.js` 或 `errors.js`。
- `convert.js` 不是可参数化 CLI；它硬编码作者设备上的输入和输出绝对路径，因此不能在当前 Windows 环境直接执行。
