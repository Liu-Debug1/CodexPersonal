# 问题官——出题

## 触发

收到复盘官的错题量 M → 计算新题量 → 按题型分配 → 后台生成题目。

## 新题数量公式

```
默认基准 N = 8（用户可调）
新题量 = N - floor(M / 5)，最少 3
```

## 题型分配规则

### 第一步：难题三选二

从 {代码补全题, 简答题, 评价题} 中每天抽 2 种，各出 1 题（共 2 题）。每天轮换组合，避免连续两天抽同样的两种。

### 第二步：剩余配额分配

N - 2 题平均分配给选择题、判断题、填空题。无法整除时，优先补给选择题。

示例（N=8）：
- 代码补全 1 + 简答 1 = 2 题（难题）
- 剩余 6 题 → 选择 2、判断 2、填空 2

示例（N=5）：
- 代码补全 1 + 评价 1 = 2 题（难题）
- 剩余 3 题 → 选择 1、判断 1、填空 1

### 附加约束

- 选择题中至少 1 道为**多选**
- 判断题每题必须要求说明理由（不能只写"对/错"）

## 出题顺序

按以下顺序逐题呈现：

```
选择题 → 判断题 → 填空题 → 代码补全题 → 简答题 → 评价题
```

同题型内部按知识点从易到难排列。

## 各题型格式

### 选择题

```markdown
### Qxxx | 来源：[[笔记名]] | 创建：YYYY-MM-DD

**类型**：选择题（单选）/ 选择题（多选）

**题目**：题面

**选项**：
A. xxx  B. xxx  C. xxx

**答案**：X

**评分键**：...
**选项解析**：A ✅/❌ ...  B ✅/❌ ...  C ✅/❌ ...
```

- 选项精简为 3 个，每个干扰项反映真实常见错误
- 题干尽量不用"不是"等否定词

### 判断题

```markdown
### Qxxx | 来源：[[笔记名]] | 创建：YYYY-MM-DD

**类型**：判断题

**题目**：给出一个命题，判断对错并说明理由。

**答案**：正确/错误。理由：xxx
```

- 命题必须是有迷惑性的陈述，不是一眼能看出来的
- 题干用"判断下列说法是否正确，并说明理由"

### 填空题

```markdown
### Qxxx | 来源：[[笔记名]] | 创建：YYYY-MM-DD

**类型**：填空题

**题目**：题面，空位用 ________（至少 8 个下划线）标记

**答案**：xxx
```

- 每个空位必须有 `________` 标记，逐空检查
- 代码补全型不归入此类——代码补全单独作为难题类型

### 代码补全题

```markdown
### Qxxx | 来源：[[笔记名]] | 创建：YYYY-MM-DD | #重点（如果是重点笔记）

**类型**：填空题（代码补全）

**题目**：给完整的上下文代码，在关键语句处留空

**答案**：补全的代码
```

- 信息完整性双检：① 背景够不够理解代码意图 ② 答案是否被题目泄露
- 给完整上下文（类定义、函数签名），只留核心逻辑空

### 简答题

```markdown
### Qxxx | 来源：[[笔记名]] | 创建：YYYY-MM-DD

**类型**：简答题

**题目**：开放性问题，要求说明原理/分析原因/对比方案

**答案**：要点式标准答案
```

### 评价题

```markdown
### Qxxx | 来源：[[笔记名]] | 创建：YYYY-MM-DD | #重点（如果是重点笔记）

**类型**：简答题（评价层）

**题目**：论证在特定场景下哪种方案更优，或评价某设计的优劣

**答案**：标准论证要点
```

## 认知层次要求

- 记忆层 < 30%
- 至少 1 道达到分析/评价层（由代码补全/简答/评价题覆盖）
- 每道题标注认知层（记忆/理解/应用/分析/评价）

## 命题前自检

1. **日期**：从 `# currentDate` 读取今天日期
2. **题源优先**：`#重点` 笔记多出题；优先出有代码示例的知识点
3. **填空题下划线**：逐空检查，每个空位都有 `________`
4. **代码补全题**：背景够 + 答案未泄露
5. **判断题**：命题有迷惑性，不是送分题
